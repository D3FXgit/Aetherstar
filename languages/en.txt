# ===========================================================================
# AetherStar language file -- English (the reference language)
#
# Every other language is a copy of this file with the right-hand sides
# translated. Step-by-step how-to: docs/translating.md. Key naming and rules
# for developers: docs/i18n-conventions.md.
#
# FORMAT
#   - Plain UTF-8 text, one entry per line:      key = value
#   - Lines starting with # are comments. Blank lines are ignored.
#   - Header lines start with @ and describe the file itself:
#       @code: de          language code (the FILE NAME wins: de.txt is "de")
#       @name: Deutsch     how the language is listed in Settings, in itself
#       @fallback: de      optional: where missing texts come from before
#                          English (useful for de-AT, pt-BR, ...)
#   - Only translate the part right of the first "=". Never change the key.
#   - Spaces around key and value are ignored. A "#" or "=" inside a value
#     is just text.
#   - \n inside a value is a line break, \t a tab, \\ a backslash.
#   - {name} is a placeholder the game fills in (a number, a name ...).
#     Keep it exactly as written; move it wherever your grammar wants it.
#   - Plurals: the same key with one suffix per plural form, e.g.
#       settings.mics.players.count.one   = {count} player in your roster.
#       settings.mics.players.count.other = {count} players in your roster.
#     The forms are the Unicode CLDR plural categories: zero, one, two, few,
#     many, other. Write the ones your language uses; "other" is always
#     needed. A ".zero" entry, if you add one, is used for exactly 0.
#   - Anything you leave out (or leave empty) is shown in English.
# ===========================================================================
