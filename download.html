Windows 10 or 11, 64-bit, or macOS on Apple silicon

At least one. USB mics, headsets or an audio interface, up to eight
Songs
UltraStar songs of your own. Where to get them
Optional
A second monitor or TV for the audience window, a gamepad

Installing

The installers aren't code-signed yet, so your system will ask before it opens them the first time.

Windows

If SmartScreen says Windows protected your PC, choose More info, then Run anyway. You can pick the install folder during setup.

Mac

Drag AetherStar into Applications. If macOS says it can't check the app, open System Settings › Privacy & Security and choose Open Anyway. Allow microphone access when asked, the app needs it to hear you sing.

New in 1.1

Source code

AetherStar is open source under the MIT licence. The code, the issue tracker and every release are on GitHub.

To build it yourself you need Node.js 22 and a Rust toolchain, plus Xcode Command Line Tools on a Mac or the Visual Studio Build Tools on Windows.

npm install
npm run dev     # run from source
npm run dist    # build installers

Questions

Where do I get songs?

AetherStar plays songs in the UltraStar format. It doesn't include or download any. The Songs page explains the format, the USDB database and USDB Syncer.

Which microphones work?

Any microphone your computer can see: USB mics, headsets, or the inputs of an audio interface, one channel per singer. Mic check shows a live tuner for each input, so you can test before the party.

Do I have to sing in the original octave?

No. Any octave counts. AetherStar compares the note you sing, not how high or low you sing it.

My speakers are Bluetooth. Is that a problem?

Run the calibration once in Settings. It measures how late your speakers and mic are and shifts the scoring to match.

Does AetherStar send anything over the internet?

No. Songs, players and scores stay on your computer, and your voice is analysed on the device.

What does it cost?

Nothing. AetherStar is free and open source under the MIT licence.
