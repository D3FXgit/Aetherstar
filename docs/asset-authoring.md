# Asset Authoring

Where AetherStar looks for songs, sounds, images and icons, and how to replace them.

## Song folders (UltraStar format)

Add a folder of songs in **Settings > Song Folders**. The app scans it and all its subfolders.
Each song needs its own folder:

```
Songs/
  Artist - Title/
    Artist - Title.txt   # the UltraStar chart
    Artist - Title.mp3   # audio
    Artist - Title.mp4   # optional video
    Artist - Title.jpg   # optional cover art
```

How charts are found:

- A `.txt` counts as a chart only if its first 16 KB has a `#TITLE` line plus at least one of
  `#BPM`, `#ARTIST`, `#MP3` or `#AUDIO`. Other `.txt` files, such as a readme, are ignored.
- A folder with a chart is a song folder. Its subfolders are not scanned, so don't nest songs.
- If a folder has several charts, a solo chart is picked before a duet, then the shortest file
  name. `Artist - Title.txt` wins over `Artist - Title (Acoustic).txt`.

`fixtures/sample-song/` is a complete song folder you can add to try the app: the original demo
song *First Light* by AetherStar, with a backing track, a guide-vocal stem and a cover, all
generated by `scripts/generate-demo-audio.mjs` (see its
[README](../fixtures/sample-song/README.md)). It is also the built-in sample song and the chart
most tests read.

### Tags the app reads

| Tag | Notes |
| :--- | :--- |
| `#TITLE` | Required. |
| `#ARTIST` | Shown in the song list. |
| `#BPM` | Required, greater than 0. Comma decimals (`326,9`) work. |
| `#GAP` | Milliseconds from the start of the audio to the first beat. |
| `#AUDIO` or `#MP3` | The audio file. `#AUDIO` wins if both are set. |
| `#VOCALS`, `#INSTRUMENTAL` | Optional separate vocal and backing tracks. |
| `#VIDEO`, `#VIDEOGAP` | Optional video, and its offset in seconds. |
| `#COVER` | Optional cover image. |
| `#VOLUME` | Optional per-song volume, as a multiplier. |
| `#START`, `#END` | Play only part of the song. `#START` is in seconds, `#END` in milliseconds. |
| `#PREVIEWSTART` | Where the song preview starts, in seconds. Picked up on the next scan. |
| `#RELATIVE` | `YES` for charts whose beats restart at 0 on each line. |
| `#ENCODING` | Used only when the file isn't valid UTF-8. |

Note lines use the usual markers: `:` normal, `*` golden, `F` freestyle (not scored), `R` rap and
`G` golden rap. Duets use `P1` and `P2` sections (`P 1` and `P 2` work too).

### How media files are found

- If the file named in `#AUDIO`/`#MP3`, `#VIDEO` or `#COVER` doesn't exist, the app uses any file
  of the right type in the song folder. Renamed files and wrong extensions usually still work.
- `#VOCALS` and `#INSTRUMENTAL` must name the exact file. Without it, the song plays the full mix.
- Audio: `.mp3`, `.ogg`, `.wav`, `.m4a`, `.flac`, `.aac`.
- Cover: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.webp`.
- Video: only `.mp4` and `.webm` play. For `.avi`, `.mpg` and other formats, add an `.mp4` or
  `.webm` copy to the folder. The app uses it without a tag change. Otherwise the cover is shown.

### Text encoding

Charts in UTF-8 (with or without a byte order mark) and UTF-16 (with a byte order mark) are read
as-is. For other files the app uses the `#ENCODING` tag (for example `CP1250`, `CP1251`,
`CP1252`). Without that tag it uses Windows-1252, the most common legacy encoding.

## Sound effects

Sounds live in `assets/sfx/` and are built into the app. To replace one, save a new file under the
same name and rebuild. Files starting with `placeholder_` are stand-ins meant to be replaced. See
[`assets/sfx/README.md`](../assets/sfx/README.md) for what each sound is used for.
`song_selected.wav` has its length written into `src/audio/sfxAssets.ts`. A replacement with a
different length needs that value updated.

All bundled sounds and the menu music are original and generated by
`scripts/generate-sound-assets.mjs` (MIT, like the rest of the repository). Run
`npm run generate:sounds` to rebuild them after changing the script.

## Images

`assets/ui/crown.png` is the crown on the results screen. Replace it with a file of the same name.
See [`assets/ui/README.md`](../assets/ui/README.md) for size and transparency rules.

Hit effects are drawn in code. They don't use image files.

## Menu music

By default the menus play random songs from the player's library. `menu_music/menu_loop.wav` is
the built-in track: it plays when **Menu music source** is set to **Built-in track**, and as the
fallback when the library is empty or its songs can't be loaded. Replace it with a file of the same
name. The track loops, so it should have no silence at the start or end. See
[`menu_music/README.md`](../menu_music/README.md).

## App icon

Icons go in `build/`:

- `icon.icns` for macOS
- `icon.ico` for Windows
- `icon.png` at 512 x 512 for Linux

electron-builder picks them up from there (`buildResources: build` in `electron-builder.yml`).
Replace the files at the same paths and sizes. No config change is needed.
