# App assets

Files here are built into the app. To replace one, save a new file under the same name and
rebuild. No code change is needed.

- [`sfx/`](./sfx/README.md): sound effects for menus, the countdown, note hits and results.
- [`ui/`](./ui/README.md): images drawn by the app, currently the results-screen crown.

Hit effects are drawn in code and don't use image files. Menu music lives in `menu_music/` at the
repo root. See [`docs/asset-authoring.md`](../docs/asset-authoring.md) for songs, music and app
icons.
